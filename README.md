# Closer

A considered little macOS utility by Parth Mudgal. See regular running apps, keep what matters open, and send normal quit requests to the rest.

This repository distributes official Closer releases. Application source is not included. Closer is **proprietary freeware**: free to download and use, with no open-source license granted. Copyright © 2026 Parth Mudgal. See LICENSE.txt.

## Installing

In Releases, choose the versioned **Closer macOS ZIP** under Assets. GitHub’s automatically generated source-code archives are not the app. Compare the download’s full SHA-256 with the supplied checksum. Extract the ZIP if needed, move Closer.app into Applications, open it and approve the normal macOS first-open confirmation if displayed.

The v0.1.0 download is for Apple silicon only, with macOS 14 as the declared minimum. It was tested on macOS 27.0.1. The app is Developer ID signed and notarized by Apple. Save important work first; each app handles its own saving and quit behavior. Closer does not force quit or automatically retry.

There is no automatic updater. For a future release, quit Closer and replace the app in Applications. No compatibility or preference-preservation guarantee is made for untested replacement updates.

Closer operates locally on your Mac. It does not collect personal information, usage analytics, or tracking data. Application preferences are stored locally and are not transmitted to the publisher. GitHub separately processes download requests under its own privacy policy.
